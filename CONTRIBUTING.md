# Contributing

Thank you for your interest in skAItch.

## What is welcome

- **Bug reports** — open an issue with the steps to reproduce, the app (web,
  desktop, survey), its version and, when possible, a small sample file.
- **Feature ideas and feedback** — open an issue or a discussion.
- **Questions** — use GitHub Discussions.

## Code contributions are not accepted for now

skAItch is open source, but not open contribution: pull requests are not
merged at this stage. Keeping a single copyright holder lets the project stay
free under the AGPL while keeping the option to fund its development later
(for example through commercial licences).

You are of course free to fork the project under the terms of the AGPL. If you
redistribute a modified version, please read `TRADEMARK.md`.

This policy may change; it will be announced here.

## Security issues

Do not open a public issue. Write to skaitch@proton.me.
